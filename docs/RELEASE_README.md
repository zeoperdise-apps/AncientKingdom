# 古都 ～Ancient Kingdom～ ブラウザ完成版

Studio Arkによる2007年の携帯Java試作をもとにした、全5階のレトロな一人称ダンジョンRPGです。三つの王印を集め、白い斧騎士を越え、忘却の王に挑みます。

## 起動

1. ZIPをフォルダーへ**すべて展開**します。
2. Node.js 22.12以降をインストールします。
3. Windowsでは `Start-Game.cmd` をダブルクリックします。ブラウザが自動で開きます。

起動先は `http://127.0.0.1:5173/` です。ブラウザが開かなければこのURLを手動で開いてください。終了は起動ウィンドウで Ctrl+C。ポート使用中のエラーが出た場合は、起動済みの古都を開くか、その起動ウィンドウを終了してから再実行します。他のプロセスは自動停止しません。

macOS/Linuxではこのフォルダーで `node server.cjs` を実行します。追加ライブラリの導入やインターネット接続は不要です。`dist/index.html` を `file://` で直接開く方法では動作しません。

## 操作と保存

W/↑ 前進、S/↓ 後退、A/D/←/→ 90度回転、E/Enter/Space 調べる。M 地図、K 記憶、I 持物、Esc 設定/閉じる。戦闘は1攻撃・2防御・3スキル・4回復薬・5魔力薬・6逃走。画面のボタンでも操作できます。大技の予告には防御、困ったら帰還糸で無料休息へ。階段・宝箱・泉は同じマスで「調べる」を使います。

行動ごとにブラウザのlocalStorageへ自動保存します（キー `ancient-kingdom.save.v1`）。戦闘中も「冒険の続きを辿る」で再開できます。**同じブラウザとURL（host/port）で起動してください。** localhost/127.0.0.1やポートが変わると別の保存場所になります。ブラウザデータの削除、プライベートモードの終了では保存が失われることがあります。セーブデータはこのZIPには含まれていません。

作品名、壁・廃墟・白騎士の画像3点、cave.mid、crash.wav/step.wav、四方向探索、属性とスキルメモリーの構想は原作 Studio Ark（2007）より継承。物語、全5階の進行と結末、戦闘・成長・保存、数値、新規ピクセル敵と3D迷宮はブラウザ版（2026）で追加しました。原曲の1176音はWeb Audioで再生するため、元のMIDI音源とは音色が異なります。
