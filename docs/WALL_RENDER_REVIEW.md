# 現在セルの側壁・横道の見え方を改善

2026-11-14。ユーザー指摘「真横に壁があるか見れない」を受けた限定修正。ゲームの論理マップと保存内容は変更していない。

## 原因と変更

従来は探索カメラがセル中心にあり、現在セルの側壁/横道が視野の端へ隠れていた。1マス先の壁と現在地の左右を混同しやすく、特に縦画面で判断できなかった。

- 探索カメラを向きの後方へ1.0だけ下げた（セル幅3.4）。水平視野は90度。現在セルの手前の左右を画面へ入れる。
- 360pxでは3D描画領域をHUDと下部操作の間へ収め、極端な縦視野を避けた。戦闘時のカメラ/敵の見かけの大きさは従来の方式を維持。
- 開口に細い暗色の縁と床の敷居を設け、手前のセル境界と横道の奥行きを示した。壁そのものは元の素材/暖色のまま。
- 現在セルの左右が開いている場合だけ、控えめな「← 横道」「横道 →」を表示。情報は現在セルの壁bitから直接取得し、旋回/移動ごとに更新する。

同時に確認できた2件を修正した。移動/旋回ボタンだけはキーボードの150ms間隔制限がなく、連打すると145ms補間が曲がり角を斜めに横断した。commandの共通入口へ制限を一本化し、遅れた描画フレームの途中値も新しい入力時の時刻で確定する。戦闘/メニューはこの制限の対象外。また、低解像度バッファを幅800/高さ500で別々に制限していたためピクセルの縦横倍率が不揃いだった。比例縮小へ変更した。これは壁配置や画面上の透視座標のずれとは区別する。
