王国は滅び、記憶だけが地下に残った。
三つの王印を集め、最後の灯火を取り戻せ。

『古都 ～Ancient Kingdom～』は、石の回廊を一歩ずつ進む、一人称のダンジョンRPGです。2007年の携帯Java版をもとに、ブラウザで最後まで遊べる作品として制作しました。無料で遊べます。

### ゲームの特徴

- 全5階の迷宮を探索し、宝箱と泉を見つけ、守護者に挑む。
- 炎・風・水の生来属性を選び、限られたメモリーにスキルを組み合わせる。
- 敵の予告と属性の弱点を読んで戦うターン制バトル。
- 自動保存で中断・再開。戦闘不能時は救出、または戦闘前から再挑戦。
- 原作の壁、白い斧騎士、音楽を継承した、レトロな迷宮の雰囲気。

### 操作

画面のボタン、またはキーボードで操作できます。

- W / ↑：前進、S / ↓：後退
- A・D / ←・→：向きを変える
- E / Enter / Space：足元を調べる
- M：地図、K：記憶、I：持物、Esc：設定・閉じる
- 戦闘中は 1：攻撃、2：防御、3：スキル、4：回復薬、5：魔力薬、6：逃走

階段・宝箱・泉は、同じマスに立って調べてください。大技の予告には防御。拠点では無料で休息できます。

### プレイ環境と保存

Chromeでのプレイを推奨します。ゲームをクリックすると音が有効になります。音量・ミュートは設定から変更できます。

進行は行動ごとにブラウザへ自動保存します。続きは同じ端末・ブラウザで、このページから遊んでください。ブラウザのデータ削除やプライベートモードでは保存が失われることがあります。保存できない場合はゲーム内に案内を表示します。ローカル配布版の保存とは別になります。

### クレジット

原作：Studio Ark · 2007
ブラウザ版追加：2026

原作の作品名、画像、音楽・効果音、四方向探索とスキルメモリーの構想を継承。物語、全5階の進行・結末、戦闘・成長・保存などはブラウザ版で追加しました。

原曲のMIDI音符をシンセで再生しているため、原作MIDI音源とは音色が異なります。
